### 👨‍💻 Sobre Mí

Soy un **Desarrollador Mobile (React Native)** con un background único que combina **Gestión Comercial** y **Seguridad**. No solo escribo código; diseño soluciones que optimizan operaciones reales y aumentan ventas.

Me especializo en arquitecturas **Offline-First**, sistemas de alta disponibilidad y en la integración de lógica de negocio compleja en interfaces nativas fluidas. Busco roles desafiantes donde pueda aplicar esta visión integral para contribuir al éxito técnico y comercial de la empresa.

### 🏗️ Arquitectura Destacada: Mobile Commerce Ecosystem

He diseñado e implementado una arquitectura completa para aplicaciones de venta móvil y logística. Este es mi estándar de calidad:

| Feature | Implementación Técnica |
| :--- | :--- |
| **🔌 Offline Capability** | Implementación de `expo-sqlite` para caché de datos robusto, permitiendo operación total sin conexión a internet. |
| **🔄 Real-Time Sync** | Sincronización instantánea de órdenes, stock y estados mediante **Firebase Realtime Database**. |
| **⚡ Performance** | Optimización de listas masivas (miles de productos) utilizando `FlashList` para mantener 60fps. |
| **📍 Native Features** | Uso intensivo de Geolocalización (Maps), Cámara (Escaneo QR/Barcodes) y Sensores del dispositivo. |
